Build a simple web-based project called:

"Stock Alert – Retail Store Inventory Reorder Alert System"

The purpose of the project is to help a retail store manage products, track stock movements, and automatically generate reorder alerts when stock becomes low.

Use:
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- HTML
- CSS
- JavaScript
- Thymeleaf
- REST APIs

Keep the project simple. Do not use DTOs, Lombok, complex security, microservices, or unnecessary advanced architecture.

Use this structure:

com.example.stockalert
├── controller
├── model
├── repository
├── service
└── resources/templates

Create these entities:

1. Products
- productId
- productName
- category
- price
- quantity
- reorderLevel

2. StocksMovement
- movementId
- quantity
- movementType (IN/OUT)
- movementDate
- product

A product can have many stock movements, so use @ManyToOne from StocksMovement to Products.

3. Reorderalerts
- alertId
- message
- status
- alertDate
- product

A product can have many reorder alerts, so use @ManyToOne from Reorderalerts to Products.

Create repositories using JpaRepository for all three entities.

Create service classes:
- ProductService
- StockMovementservice
- ReorderAlertservice

ProductService should support:
- Add product
- Get all products
- Get product by ID
- Update product
- Delete product
- Check whether stock is below the reorder level

StockMovementservice should:
- Add stock movement
- Get all movements
- Get movement by ID
- Delete movement
- If movement type is IN, increase product quantity
- If movement type is OUT, decrease product quantity
- After changing quantity, check:

quantity <= reorderLevel

If the condition is true, automatically create a Reorder Alert.

Example:
Quantity = 20
Reorder Level = 5
OUT = 16
New quantity = 4
Since 4 <= 5, create a reorder alert.

Create REST controllers:

ProductController:
POST /products
GET /products
GET /products/{id}
PUT /products/{id}
DELETE /products/{id}

StockmovementController:
POST /stock-movements
GET /stock-movements
GET /stock-movements/{id}
DELETE /stock-movements/{id}

ReorderAlertController:
POST /reorder-alerts
GET /reorder-alerts
GET /reorder-alerts/{id}
DELETE /reorder-alerts/{id}

Create a simple HomeController using @Controller that opens index.html at:

GET /

Create a simple Thymeleaf frontend in:

src/main/resources/templates/index.html

The UI should contain:

1. Add Product form
- Product Name
- Category
- Price
- Quantity
- Reorder Level
- Add Product button

2. Products table
- ID
- Name
- Category
- Price
- Quantity
- Reorder Level

3. Reorder Alerts table
- Alert ID
- Message
- Status
- Date

4. Stock Movement form
- Product ID
- Quantity
- Movement Type (IN/OUT)
- Add Movement button

5. Stock Movements table
- Movement ID
- Product ID
- Quantity
- Type
- Date

Use JavaScript fetch() to communicate with the Spring Boot REST APIs.

Use MySQL database named:

stockalert

Use application.properties for the database configuration.

The overall architecture should be:

User
↓
HTML/CSS/JavaScript + Thymeleaf
↓
Controller
↓
Service
↓
Repository
↓
MySQL

Main workflow:

User records a stock movement
↓
Controller receives the request
↓
Service finds the product
↓
IN increases quantity / OUT decreases quantity
↓
Updated quantity is saved
↓
System checks reorder level
↓
If quantity <= reorderLevel
↓
Create reorder alert
↓
Save alert in MySQL
↓
Display updated products, movements and alerts in the UI.

Keep the UI very simple and suitable for a college project.

Also make sure the project can be tested using Postman and run locally using Spring Boot on port 8080.
